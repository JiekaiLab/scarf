# SCARF Application-Oriented Downstream Analyses

This folder contains application-oriented downstream analyses designed to strengthen the biological utility story beyond basic embedding visualization.

The scripts consume outputs generated by `downstream_tasks/embedding.ipynb`:

- `rna_cell_embs.npy`
- `atac_cell_embs.npy`
- `cell_names.npy`
- `labels.tsv.gz` when labels are available

## Recommended Reviewer-Facing Analyses

1. **scATAC-to-scRNA reference mapping**
   - Build a labeled scRNA reference in SCARF RNA embedding space.
   - Query unlabeled or held-out scATAC cells in SCARF ATAC embedding space.
   - Report accuracy, macro-F1, per-cell-type F1, and confusion matrix.

2. **Cross-dataset generalization**
   - Use one dataset as the labeled reference and another dataset as query.
   - This is stronger than random train/test splits because it tests transfer across batches, donors, platforms, or studies.

3. **Few-shot annotation**
   - Subsample 1, 5, 10, 50 labeled cells per type from the reference.
   - Query held-out cells and report how quickly performance improves with few labels.
   - This directly supports the foundation-model value claim.

4. **ATAC-to-RNA imputation validation**
   - Validate predicted gene expression against matched truth using marker genes, DEG/pathway gene sets, and per-cell correlations.
   - This is more biologically meaningful than only reporting global Pearson correlation.

## Inputs

Each embedding directory should look like this:

```text
example_embed_dir/
  rna_cell_embs.npy
  atac_cell_embs.npy
  cell_names.npy
  labels.tsv.gz
```

`labels.tsv.gz` should have two columns with no header:

```text
barcode,cell_type
AAAC...,CD4 T
AAAG...,B cell
```

Tab-separated files are also accepted.

## Example Commands

### 1. scATAC Query to scRNA Reference

```bash
python reference_mapping.py \
  --reference-emb ref/rna_cell_embs.npy \
  --reference-names ref/cell_names.npy \
  --reference-labels ref/labels.tsv.gz \
  --query-emb query/atac_cell_embs.npy \
  --query-names query/cell_names.npy \
  --query-labels query/labels.tsv.gz \
  --output-dir results/reference_mapping_atac_to_rna \
  --k 15
```

### 2. Cross-Dataset Transfer

```bash
python cross_dataset_generalization.py \
  --reference-dir dataset_A_embeds \
  --query-dir dataset_B_embeds \
  --direction atac_to_rna \
  --output-dir results/cross_dataset_A_to_B \
  --k 15
```

### 3. Few-Shot Annotation

```bash
python few_shot_annotation.py \
  --embedding-dir dataset_embeds \
  --modality atac \
  --shots 1 5 10 50 \
  --repeats 10 \
  --output-dir results/few_shot_atac \
  --k 15
```

### 4. ATAC-to-RNA Biological Validation

```bash
python rna_imputation_validation.py \
  --truth-h5ad hPbmc.gex.h5ad \
  --prediction-h5ad predict.gex.h5ad \
  --marker-genes marker_genes.tsv \
  --output-dir results/rna_imputation_validation
```

`marker_genes.tsv` is optional. It should contain:

```text
gene_id	cell_type
ENSG00000167286	CD4 T
ENSG00000156738	B cell
```

## Suggested Manuscript Framing

Use these experiments to move the story from "SCARF produces embeddings" to:

> SCARF enables reference-based annotation and cross-modal transfer from chromatin accessibility to transcriptomic cell identity and gene-expression programs, especially when labels or paired multi-omic data are limited.
